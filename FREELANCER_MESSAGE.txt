**Quick Setup Overview:**
1. Clone the repository to your server
2. Install dependencies (composer install --no-dev)
3. Configure .env file with your database credentials
4. Run migrations (php artisan migrate --force)
5. Build frontend assets (npm run build)
6. Set document root to the 'public' directory
7. Create storage link (php artisan storage:link)
8. Optimize for production (cache config, routes, views)
